# 四觉一体食品感官系统规划（视觉 · 味觉 · 嗅觉 · 触觉）

> 状态：远期架构规划 ｜ 建立日期：2026-08-06
> 定位：本系统（智果 AI 品控系统）的远期演进方向；毕设阶段只做"两觉半"，其余作为展望与技术储备。

---

## 一、愿景与定位

把人工食品感官评价（看、闻、尝、摸）数字化：
**仪器采集四维感知数据 → AI 多模态融合 → 预测感官品质（新鲜度/等级/货架期）→ 与人工感官评分对标**。

- 对食品行业的意义：人工感官评定主观、耗时、难批量，仪器+AI 可做到客观、快速、无损（或微损）
- 对你的专业契合：这是食品感官科学（Sensory Science）与人工智能的交叉，是食品专业学生做 AI 的"合法且加分"路径
- 差异化卖点：市面上多是单一模态（视觉分级/电子鼻/电子舌），**四觉一体 + 多模态融合**是罕见且成体系的

## 四、与食品感官科学方法论衔接（论文"灵魂"）

1. **人工感官评分作为"真值"**：QDA 定量描述分析法（培训 5~8 人评鉴小组），对每批样本按色/香/味/质地打分 1~9 分
2. **仪器指标与感官评分做相关性分析**：皮尔逊相关系数 + 线性/多元回归，回答"仪器能否替代人工"
3. **主成分分析（PCA）**：找出四觉特征中最能解释感官差异的主成分，可作论文图表
4. **一致性检验**：机器 vs 人工分级用 Kappa 一致性（≥0.6 合格、≥0.8 优）
5. **实验设计**：单因素/正交设计控制品种、温度、存储天数等变量

> 这一套方法写进论文，就是标准的"食品科学实验 + 仪器分析 + 智能算法"结构，答辩专家一看就认。

## 五、毕设范围与远期路线（分阶段）

### 阶段一（毕设主线：视觉 + 嗅觉 + 触觉/理化补充）
- 视觉：现有系统（外观/缺陷/等级）
- 嗅觉：电子鼻采集 120 个红富士（3 级×40），S-G 滤波 + 60 维特征 + 四模型对比（enose 方案已就绪）
- 触觉/理化：同一批苹果测硬度 + 糖度 + pH，作为补充特征列
- 融合实验：视觉特征 + 气味特征 → 多模态融合模型，对比单模态 vs 多模态准确率（这是论文核心创新点之一）
- 人工感官评分：对同批样本做 QDA 评分，做仪器-感官相关性分析

### 阶段二（系统集成）
- 检测结果页展示四维数据面板：外观图、气味曲线、硬度/糖度数值
- 新增"感官数据"记录表，与检测记录关联（sample_id 唯一）

### 阶段三（远期，论文展望 + 后续开发）
- 完整电子舌（离子选择电极阵列），补齐"味觉指纹"
- 自动穿刺装置（步进电机 + 压力传感器）替代手持硬度计，曲线自动录入
- 剩余货架期预测（时间序列建模，电子鼻连续多天数据）
- 便携无线化：ESP32 数据直接推送到系统，手机端展示

## 六、数据采集联动方案（同一批样本的多模态数据集）

```
sample_id = 日期 + 品种 + 序号（如 20260806_apple_001）
├─ 视觉：拍照 1~3 张 → 存入 dataset_collected/多模态/视觉/
├─ 嗅觉：电子鼻顶空采样 120s → data/raw/s001_fresh_day0.csv
├─ 触觉：硬度计读数 + 重量 → 记录表（硬度、重量）
├─ 理化：糖度 Brix + pH → 记录表
└─ 人工感官：QDA 评分表（色/香/味/质地各 1~9 分）
```

- 每个样本一个文件夹/一条记录，四觉数据统一关联
- 训练时按 sample_id 对齐，缺失模态用均值填充或样本剔除（先剔除，数据够了再填充）
- 数据集规模建议：毕设 120~200 个样本，每个样本四觉全量；论文核心实验约 60~100 个全量样本即可支撑统计分析

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| 电子舌难做准（交叉响应/标定） | 毕设阶段只做糖度+pH 简化理化；完整电子舌放远期 |
| 触觉数据单一（硬度一个数） | 加重量与密度估算；远期做穿刺力曲线 |
| 感官评分主观 | 培训评鉴小组 + 多人均值 + 报告标准差；与仪器相关性分析时注明局限 |
| 多模态样本量小 | 优先保证全量样本质量（120 个）；统计方法用小样本稳健版本 |
| 环境干扰（温湿度） | 电子鼻方案已含环境控制（20~28℃、湿度 50~70%），坚持执行并记录 |
| 时间不够 | 主线只做视觉+嗅觉融合，触觉/理化作为"补充特征"而非独立章节 |
