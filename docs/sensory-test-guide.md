# 食品感官测试指标指南（各感官测什么、怎么测）

> 依据：食品感官分析国家标准体系（GB/T 10220 感官分析方法学总论、GB/T 16860 定量描述分析 QDA）、
> 食品质地学 TPA 质构分析、CIELAB 色度学，以及苹果品质检测行业通行指标（糖酸比、可滴定酸度等）。
> 用途：指导你采集"四觉一体"数据，每个指标在系统里都有对应字段，填进 multimodal_data 即可跑分析。

## 一、五感对应食品评价维度（总览）

1. 视觉（看）：颜色、大小、形状、表面缺陷、光泽 —— 决定"第一印象"与商品等级
2. 嗅觉（闻）：香气强度、异味、腐败气味 —— 反映新鲜度与内部生化变化
3. 味觉（尝）：甜、酸、苦、咸、鲜、涩 —— 决定可接受度与风味品质
4. 触觉（摸/咬）：硬度、弹性、脆度、咀嚼性、多汁 —— 决定质地口感
5. 听觉（听）：脆响、敲击声 —— 膨化/生鲜类脆度与内部空心的辅助判断（可选创新点）

其中 1 和 5 可用图像/音频传感器，2 用电子鼻，3 用糖度计/pH/电子舌，4 用质构仪/硬度计。

## 二、视觉：测什么

必测（图像可直接提取，系统已支持）：
- 颜色：CIELAB 三通道（L* 亮度、a* 红绿、b* 黄蓝），对应字段 lab_l / lab_a / lab_b
- 着色率：红色覆盖果面的比例 %，字段 color_coverage
- 大小：果径/横径 mm（需固定拍摄距离或放标尺），字段 fruit_diameter_mm
- 形状：果形指数（纵径/横径），字段 shape_index
- 表面缺陷：碰伤、腐烂、斑点、虫眼、畸形（系统检测已输出缺陷面积与类型）

可选（论文加分）：
- 光泽度（需光泽度仪），与新鲜度相关
- 色差 DeltaE：样品与标准色的色差，用于"货架期颜色变化"分析

## 三、嗅觉：测什么

必测（电子鼻，系统已支持 10 通道）：
- 挥发性气体响应曲线：MQ 系列 + BME680 + SGP30，60 维特征（起始/稳态/极差/斜率/AUC/比值）
- 空罐基线：每次实验先采 baseline，训练时做差分校正

可选（论文加分）：
- 特定标志物：苹果的己醛、2-甲基丁酸乙酯、乙醇（腐败标志），可用 GC-MS 或气体传感器针对性测
- 异味评分：人工 QDA 的 qda_odor 与电子鼻特征做相关性（系统 sensory_correlation.py 已支持）

## 四、味觉：测什么

必测（理化代替，系统已支持）：
- 可溶性固形物 Brix（糖度计），字段 brix
- pH（pH 笔），字段 ph
- 可滴定酸度 TA %（NaOH 滴定），字段 ta
- 糖酸比 = Brix / TA，字段 sugar_acid_ratio —— 苹果风味最重要的综合指标

可选：
- 维生素C mg/100g（2,6-二氯靛酚滴定或试纸），字段 vitamin_c
- 电子舌（远期）：酸、甜、苦、咸、鲜五通道离子响应，做"滋味指纹"

## 五、触觉：测什么

必测（手持/简易，系统已支持）：
- 果肉硬度 kg/cm2（手持水果硬度计），字段 hardness
- 单果重 g（电子秤），字段 weight_g

推荐（质构仪 TPA，论文含金量高）：
- 弹性 springiness、内聚性 cohesiveness、咀嚼性 chewiness，字段 tpa_springiness / tpa_cohesiveness / tpa_chewiness
- 出汁率 %（榨汁称重），字段 juice_pct

## 六、人工感官 QDA：测什么（作为"真值"）

基础五项（系统已支持）：外观颜色、气味总体、滋味总体、质地总体、总体接受度
扩展六项（已加字段）：甜味强度、酸味强度、涩味强度、果香强度、脆度、多汁性

方法：培训 5~8 人评鉴小组，每项 1~9 分，取均值作为该样本的感官真值，与仪器指标做相关性分析。

## 七、苹果当前推荐的最小必测集（按性价比）

拍照 + 电子鼻采样 + 糖度 + pH + 滴定酸 + 硬度 + 重量 + QDA 基础五项，即可支撑毕业设计主线。
预算够再加：TPA 质构、Lab 色差、出汁率。电子舌和 GC-MS 留作远期/展望。

## 八、数据进系统

- 感官数据页（/sensory）：手动录入全部理化与 QDA 字段，一键导出 CSV
- 电子鼻页（/enose）：拖拽 CSV 出曲线与特征
- 脚本：build_multimodal_table / multimodal_fusion_experiment / sensory_correlation 自动读新增列
