# 苹果表面缺陷识别程序 — 设计文档

## 概述

基于 Python + OpenCV 的苹果表面缺陷识别程序，通过传统图像处理技术检测苹果表面的异常区域，并根据缺陷面积占比进行三等级品质分级。

## 技术栈

- **语言：** Python 3.13
- **核心库：** OpenCV 4.13、NumPy 2.1
- **UI：** 命令行 + 可视化输出图片

## 程序结构

```
├── apple_defect_detector.py   # 主程序

├── output/                    # 结果输出目录
```

## 核心处理流程

### 第 1 步 — 图像预处理（preprocess）

1. 调整图片到统一尺寸（宽 500px，保持宽高比）
2. 高斯模糊（5×5 核）去噪
3. 转换到 HSV 色彩空间

### 第 2 步 — 苹果区域分割（segment_apple）

1. 设定 HSV 阈值范围提取苹果区域（红色/绿色苹果通用范围）
2. 形态学开运算 + 闭运算去除噪点、填充空洞
3. 查找最大连通轮廓，确认为苹果区域
4. 生成苹果区域的 mask

### 第 3 步 — 缺陷检测（detect_defects）

1. 在 HSV 空间分析苹果区域内的像素异常
2. 检测暗色/褐色区域（低 Value、特定 Hue 范围的像素）
3. 检测异常纹理区域（高方差局部区域）
4. 形态学操作合并邻近缺陷区域
5. 查找缺陷轮廓并在原图上标注

### 第 4 步 — 品质分级（classify_quality）

缺陷占比 = sum(缺陷像素) / sum(苹果区域像素)

| 等级 | 条件 | 颜色标识 |
|------|------|----------|
| 🟢 优质 Premium | 缺陷占比 < 3% | 绿色 |
| 🟡 合格 Standard | 3% ≤ 缺陷占比 ≤ 15% | 黄色 |
| 🔴 不合格 Reject | 缺陷占比 > 15% | 红色 |

### 第 5 步 — 输出展示（show_result）

1. 在原图上用红色轮廓标出缺陷区域
2. 左上角显示品质等级 + 缺陷比例
3. 图片保存到 output/ 目录（文件名加时间戳）
4. 控制台打印详细分析报告

## 使用方法

```bash
# 单张图片检测
python apple_defect_detector.py images/apple.jpg

# 批量检测目录
python apple_defect_detector.py images/
```
