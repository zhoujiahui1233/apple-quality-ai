# 多品类食品品质检测系统 — 设计文档

- 日期: 2026-07-31
- 状态: 待用户审查
- 定位: 本科毕业设计（食品科学与工程专业）

## 1. 背景与目标

### 1.1 现状
已有苹果表面缺陷检测系统（四模型 SVM/RF/DL/YOLO、分割、可视化、数据闭环雏形、移动端、报告导出）。

### 1.2 目标
升级为多品类食品品质检测系统，覆盖苹果、面包、饮料三类食品的表面品质检测与分级，作为本科毕业设计。

### 1.3 论文题目（建议）
基于机器视觉与深度学习的多品类食品品质无损检测与分级研究

### 1.4 成功标准
1. 三类食品均可完成表面检测与三级分级（优等/合格/不合格）
2. 四模型在所有品类上运行，产出准确率矩阵 + 显著性分析
3. 机器检测 vs 人工感官评价的一致性验证（Kappa）
4. 机器分级 vs 理化指标的相关性分析
5. 数据闭环（拍到存到训到升级）可运转
6. 系统稳定运行（自动重启、备份、日志轮转）

## 2. 整体架构

- config.py: 集中配置
- app.py: Flask 主服务（路由瘦身）
- models.py: 数据库模型（扩展品类/标签字段）
- detector/: 检测引擎包（品类适配器接口、统一检测管线、品类插件、可视化）
- services/: 业务逻辑层（检测编排、数据集管理、统计+显著性分析）
- templates/ + static/: 前端
- dataset_collected/: 收集的数据集
- backups/: 数据库备份
- docs/superpowers/specs/: 设计文档

### 2.1 品类适配器接口（detector/base.py）

- category_id: apple / bread / beverage
- display_name: 苹果 / 面包 / 饮料
- detect_surface(img_bgr, mask, contour): 表面缺陷检测
- classify_grade(result): 品质分级（优等/合格/不合格）
- visualize(img_bgr, result): 结果可视化

注册机制：detector/registry.py 维护品类注册表，新增品类 = 新插件类 + 注册一行，前端自动出现新品类。

## 3. 统一检测流程

上传图片 → 选品类（或自动识别）→ 预处理（缩放/增强）→ YOLO 定位食品区域
→ 品类插件.detect_surface() → 品类插件.classify_grade()
→ 四模型对比（SVM/RF/DL/YOLO）→ 可视化 → 结果入库 → 前端展示

四模型对比在所有品类上运行，为显著性分析提供跨品类数据矩阵。

## 4. 品类算法设计

### 4.1 苹果（已有，迁移）
表面缺陷（疤痕/腐烂/磕伤/污点）、阴影过滤、HSV 分割。

### 4.2 面包（新）
- 霉斑: HSV 绿色/灰色/白色异常斑块（区别于面粉正常白）
- 焦糊: 深褐色区域（低亮度+高饱和）
- 形状残缺: 轮廓圆度/椭圆拟合偏离度
- 异物: 与面包主体色差异大的小区域

### 4.3 饮料（新，瓶装表面）
- 液位异常: 瓶身区域颜色梯度突变线位置
- 瓶盖完整: 瓶盖区域颜色一致性+边缘完整性
- 瓶身污渍/划痕: 瓶身透明区域异常纹理/斑点
- 标签破损: 标签区域颜色断裂/缺失

### 4.4 统一分级规则
- 优等: 无缺陷或缺陷占比 < 5%
- 合格: 缺陷占比 5% 到 15%
- 不合格: 缺陷占比 > 15% 或检出霉斑/异物等严重缺陷

## 5. 数据闭环

手机/电脑拍照 → 检测 → 选标签保存到 dataset_collected/{品类}/{标签}/
→ 数据集管理页（浏览/筛选/删除）
→ 一键生成训练集（自动切 train/val）
→ 增量训练（SVM/RF/DL/YOLO）
→ 模型升级（版本号 + 准确率记录）
→ 系统自动加载新权重

### 5.1 模型版本管理
models_registry.json 记录版本、准确率、数据量、日期；可回滚；页面展示升级历史。

## 6. 显著性分析与验证实验

### 6.1 算法内部对比
- 四模型 x 三品类 准确率/召回率/F1 矩阵
- McNemar 检验（两两模型差异显著性）
- 卡方检验（模型预测 vs 真实标签一致性）
- 输出: 显著性分析报告页 + 可导出 Excel/CSV

### 6.2 机器 vs 人工感官评价
- 同一批样本，机器分级 vs 人工感官评价分级
- Kappa 一致性检验
- 样本数: 每品类 >= 30 份

### 6.3 机器分级 vs 理化指标
- 苹果: 硬度、可溶性固形物（TSS）、酸度
- 面包: 水分含量、比容
- 饮料: 可溶性固形物、pH
- 相关性分析（Pearson/Spearman）

### 6.4 实验设计
- 每品类独立数据集（收集+标注）
- 五折交叉验证或固定划分，保证可复现
- 训练曲线、混淆矩阵、ROC 曲线入库可查

- 一键启动脚本 start.bat
