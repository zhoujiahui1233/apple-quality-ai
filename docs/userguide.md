# 用户使用手册

## 1. 启动与访问

1. 双击 `start.bat`（或命令行运行 `python app.py`）
2. 等待约 10~15 秒（模型预热）
3. 浏览器打开 http://127.0.0.1:5020/
4. 手机访问：手机与电脑连同一 Wi-Fi，打开 `http://<电脑局域网IP>:5020/`（启动日志会显示地址）

> 提示：电脑 IP 查看方法 — Windows 运行 `ipconfig`，找"无线局域网适配器"的 IPv4 地址。

## 2. 实时监测（首页）

1. 顶部选择品类：🍎 苹果 / 🍞 面包 / 🥤 饮料 / ✨ 自动（选择会记忆，下次打开仍生效；"自动"模式由系统根据颜色特征判断品类）
2. 拖拽图片到上传区，或点击上传、拍照（手机）
3. 等待检测结果：
   - 左侧：原图 + 检测框叠加，右上角四个圆形按钮可切换 SVM / RF / DL / YOLO 可视化
   - 右侧看板：四模型准确率柱状图、品质分布环形图、实时检测日志、性能指标
4. 检测到不合格果实时，日志条目会红色闪烁提醒

## 3. 历史数据

- 历史记录按顶部所选品类分开显示（页面右上角可选择全部品类）
- 查看当前品类历史检测记录，可按等级筛选
- 点击记录进入详情页（查看原图、结果图、判定依据）
- 删除单条记录（同时删除关联图片）
- 导出报告：批次汇总报告下载

## 4. 数据统计

- 日检测量趋势、等级分布等统计图表
- 统计按顶部所选品类分开（页面右上角可选择全部品类）
- 数据批量管理同样默认作用于当前品类

## 5. 数据集管理（数据闭环）

1. 进入“数据集”页，按当前所选品类查看对应标签分组
2. 在检测结果页点击“保存到数据集”并选择标签（合格/不合格），图片自动存入
   `dataset_collected/{category}/{label}/`
3. 在数据集页可删除错误样本，或用图片上的“改标签”下拉直接把图片移动到合格/不合格
   （移动时自动重命名为新标签，避免旧标签污染分类）

### 5.1 智能保存选项（推荐开启）

检测完成后点“保存到数据集”，展开“智能选项”面板，可选择：

- 自动裁剪主体：分割出食品区域、去除背景后保存（额外生成 `_crop.jpg`）
- 质量检查：模糊/曝光异常的图片会阻止保存，避免低质量样本污染数据集
- 去重检查：与已有数据集逐图片比对，重复图片阻止保存（避免同一张图被多次存入）
- 数据增强：1 张变 4 张（翻转/旋转/亮度），小样本时快速充实数据
- 强制保存：跳过质量/去重拦截，用于确实需要保存的图片

标签选“不合格”时可进一步选择缺陷类型（碰伤/腐烂/虫眼/斑点/畸形/其他），
类型会写进文件名（如 `不合格_腐烂_xxx.jpg`），方便后续细分析，不影响一键重训分类。

点“智能分析”可先预览：质量评分、重复提示、主体裁剪效果。

### 5.2 批量标注工具（快速充实数据集）

1. 侧边栏或顶栏点击“标注”，进入批量标注页
2. 系统自动汇总当前所选品类下所有未标注图片（`dataset_collected/unlabeled/`）
3. 查看图片后按快捷键完成标注：
   - `1` = 合格　`2` = 不合格　`3` = 跳过
   - 图片会自动移动到 `dataset_collected/{category}/{label}/`，跳过图片进入 `_skipped/`
4. 顶部品类选择器可切换苹果/面包/饮料，各品类数据互不混淆

> 手机拍照上传时若未选标签，图片会进入 `unlabeled/`，随后可在标注页统一处理。

### 5.3 一键重训

在“数据集”页点击“一键重训”，或命令行运行：

```
python scripts/retrain.py --category apple --models svm rf
python scripts/retrain.py --category apple --models svm rf dl --epochs 15
```

流程：导出数据集 → 特征提取 → 训练 SVM/RF/DL → 旧模型自动备份到 `model_backups/` → 新模型登记到“模型管理”。

> 注意：训练前请确保当前品类下“合格”与“不合格”文件夹各至少有 5~10 张以上图片，
两类样本过少会导致训练失败或过拟合。

## 8. 常见问题

| 问题 | 解决 |
|------|------|
| 打开页面空白 | 等待模型加载完成（10~15 秒）后刷新；或查看 `logs/app.log` |
| 手机打不开 | 确认同一 Wi-Fi；关闭电脑防火墙或放行 5020 端口；确认启动日志显示的 IP |
| 检测失败 | 查看 `logs/app.log` 报错；图片需为 jpg/png/bmp 且小于 16MB |
| 上传无反应 | 强制刷新（Ctrl+F5）清缓存 |
| 想恢复旧服务 | 双击 `start.bat` 自动按端口重启，不影响其他 Python 程序 |
