# 电子鼻苹果新鲜度检测——实验方案（Protocol）

> 对齐杨明丽（2025）硕士论文的严谨度，按本科毕设可执行的工作量设计。
> 核心原则：**分级必须有客观依据，不能只按「放了多少天」**。

## 1. 研究目的与假设

- 目的：用电子鼻（ESP32 + MQ 阵列 + BME680 + SGP30）采集苹果顶空气体，建立
  「气味特征 → 新鲜度等级」的识别模型，并尝试与视觉检测做多模态融合。
- 假设：不同新鲜度苹果释放的挥发性气体成分与浓度存在可检测差异，
  传感器阵列响应特征可区分新鲜度等级。

## 2. 样本设计

- 品种：红富士（与市场主流一致，品种统一；后续可加 1 个对照品种作为扩展）。
- 数量：**建议 3 级 × 40 个 = 120 个**（最少 3×30=90）。
  - 想对标硕士论文加分级细度，可做 5 级 × 42 个 = 210 个（工作量大，慎选）。
- 采购：同一批购买（同产地同批次，减少个体差异）；买回后统一清洗擦干，
  随机编号 1~120，记录购买日期（第 0 天）。
- 存放：室温（20~28℃）自然存放，模拟货架；不冷藏（冷藏会改变腐败进程）。

## 3. 新鲜度分级标准（关键）

**必须每批测量客观指标**，不能只靠目测。三件套（都便宜，几十元）：

| 指标 | 工具 | 测量方法 | 备注 |
| --- | --- | --- | --- |
| 硬度 | 手持果实硬度计（指针/数显，8mm 探头） | 去皮，赤道部两处各测一次取均值，单位 kgf | 主指标 |
| 可溶性固形物 | 手持糖度计（折光仪） | 切一小片挤压汁液滴测，单位 °Brix | 辅助 |
| 感官评分 | 自制评分表（见下） | 3 人独立打分取均值 | 综合参考 |

**感官评分表**（每人每项 1~5 分）：
| 项目 | 5 分（新鲜） | 1 分（腐败） |
| --- | --- | --- |
| 色泽 | 鲜艳有光泽 | 暗淡发暗、有水渍 |
| 香气 | 果香清新 | 无果香或有酒味/酸腐味 |
| 质地 | 硬脆 | 软塌、按压凹陷不回弹 |
| 表面状态 | 干爽完整 | 湿润、粘滑、有霉点 |
| 异味 | 无 | 明显异味（酒精/酸败） |

**分级规则（示例阈值，正式实验前先用 5 个预实验样本标定你自己的阈值）**：
- 新鲜：硬度 ≥ 5.5 kgf 且 总分 ≥ 20 分
- 次新鲜：4 ≤ 硬度 < 5.5 kgf 或 15 ≤ 总分 < 20 分
- 腐败：硬度 < 4 kgf 或 总分 < 15 分，或出现霉斑/渗液

> 阈值是示例！红富士硬度区间约 4~9 kgf，你需按实际品种用预实验标定后写入记录表。

## 4. 实验条件控制（降低环境干扰）

- 环境：封闭室内，温度 20~28℃、湿度 50~70% RH（用空调+湿度计维持，每次采集前记录）。
- 传感器：每次开机预热 30 分钟，读数稳定后再开始。
- 反应室：带盖密封罐（容积固定，同一容器全程使用），苹果与传感器不直接接触
  （样品放罐内、传感器经罐盖开孔放入或旁路采样，保持气密）。
- 顺序随机化：每天测的样本随机抽取，避免「先测的都是新买的」。

## 5. 采样流程（每样本约 25 分钟）

```
预热 30min（读数稳定）
  → 空罐基线采集 2 min（--label baseline，每天开始/结束时各一次，监测漂移）
  → 放入 1 个样本，静置 15 min（气体积累）
  → 采集 2 min（稳态段，约 120 个采样点）
  → 取出样本，通风 5 min（读数回到基线附近再测下一个）
```

采样命令示例：
```bash
# 基线（每天一次）
python collect.py --port COM3 --label baseline --out data/raw/baseline_day1.csv
# 样本（每个样本一个文件）
python collect.py --port COM3 --label fresh --out data/raw/s001_fresh_day3.csv
```

## 6. 数据管理与命名规范

```
data/
  raw/            # 每个样本一个 CSV（collect.py 输出）
    baseline_day1.csv
    s001_fresh_day0.csv
    s002_mid_day3.csv
    ...
  record.xlsx     # 每个样本：编号、日期、硬度、TSS、感官分、分级结论
  features.csv    # preprocess.py 输出（每行一个样本的特征向量）
```

- 文件命名：`s{编号}_{等级}_{天数}.csv`，等级用 fresh / mid / rotten。
- 每批样本采集后，把硬度/TSS/感官分填入记录表，**由指标综合给出等级**，
  等级就是 CSV 的 label（训练目标）。
- 异常记录：采集中断、传感器读数异常（-999）、反应室泄漏等，单独标注，
  特征提取前剔除或重测。

## 7. 质量控制（证明数据可信）

- **漂移监测**：每天开始/结束测空罐基线，观察 MQ 各通道基线是否漂移；
  漂移大的天，数据用当天基线差分校正。
- **重复性**：随机抽 10% 样本重复采集一次，算特征级相关系数（≥0.9 认为可靠）。
- **剔除标准**：采集时长不足、读数含 -999 占位、明显泄漏（如反应室密封失败）。
- **统计验证**：建模后做 5 折交叉验证；模型间比较用 McNemar 检验（你的系统已有 scipy 支持）。

## 8. 实验时间表（本科毕设 12 周版）

| 周次 | 任务 | 产出 |
| --- | --- | --- |
| 1~2 | 硬件搭建、固件烧录、串口联调 | 能稳定出数据 |
| 3 | 预实验：5 个样本试跑全流程，标定分级阈值 | 分级规则定稿、流程熟练 |

| 10 | 补充实验、统计显著性检验 | 结论可靠 |
| 11~12 | 论文写作 | 初稿 |

## 9. 鲜切苹果（切片）扩展实验

背景：整果有果皮保护，顶空挥发物浓度低，传感器响应弱；切片破坏细胞结构，挥发物释放显著增强（乙醇、酯类释放量约为整果的 3~5 倍），且酶促褐变、失水、微生物污染进程加速，是电子鼻数据信噪比更高、视觉与嗅觉信号同步性更好的研究对象。系统已内置「切片检测」页面（/slice）：视觉自动计算褐变面积占比与等级，嗅觉复用电子鼻预测。

### 9.1 切片标准化（控制变量，关键）
- 刀具与切法：同一把刀，同一人操作；苹果洗净擦干后对半切开，再切成约 1.0 cm 厚片（厚度偏差尽量控制在 ±0.1 cm，可用垫块/模具辅助）。
- 每片独立编号：s{??}_slice{??}，同一苹果的多片作为平行样本。
- 切片后立即开始计时（0 min 就是切完的那一刻），后续 30/60/120/240 min 各测一次。

### 9.2 视觉采样（配合系统 /slice 页面）
- 固定机位、固定光源（避免阴影与色差），浅色背景（白纸/白盘），切片居中。
- 时间梯度：0 / 30 / 60 / 120 / 240 min 各拍 1 张，存为 slice_{??}_{min}min.jpg。
- 系统自动输出：褐变面积占比、BI（面积法与 Lab 法）、褐变等级（1~5 级）。
- 可选用色差仪测 Lab* 值作为真实标签（BI = 100(A-1.75L)/(0.31A-0.0732L)），用系统 BI 与色差仪 BI 做相关性验证（Pearson r ≥ 0.9 说明视觉模块可信）。

### 9.3 嗅觉采样（顶空，与整果流程一致）
- 切片放入密封罐，静置 3 min 后采集 2 min（切片挥发快，积累时间可比整果短）。
- 命令示例：python collect.py --port COM3 --label slice_0min --out data/raw/s001_slice_0min.csv
- 标签建议：slice_0min / slice_30min / ... / slice_240min，或按褐变等级 fresh/mid/rotten。

### 9.4 护色剂对比实验（结合食品工艺，毕设亮点）
- 三组：对照组（清水浸泡 1 min）/ VC（0.5% 维生素C溶液）浸泡组 / 柠檬酸（1% 溶液）浸泡组。
- 每组 5 片，同机位同光源，4 小时内按 0/30/60/120/240 min 拍照 + 测气味。
- 用系统输出的褐变面积%－时间折线，量化比较三组护色效果（如褐变速率 k、达 30% 时间）。
- 统计：单因素 ANOVA + Tukey 事后检验（系统「显著性分析」页面可做）。

### 9.5 时间表（插入第 3 周后）
| 周次 | 任务 | 产出 |
| --- | --- | --- |
| 3 后 | 切片预实验：1 个苹果切 3 片，连测 6 小时 | 确认视觉/嗅觉曲线趋势一致 |

## 10. 安全与卫生

- 苹果腐烂会产生霉菌孢子，操作戴手套、采完及时清理。
- 传感器为加热器件（MQ 有加热丝），通电时不要触碰传感器外壳。
- 样品测完即弃，不食用。
