# 电子鼻鲜切苹果检测——完整试验方案（收纳箱法 · 切片版）

> 适用：ESP32 + MQ-2/3/7/135 阵列 + BME680 + SGP30 电子鼻装置（面包板免焊版）
> 研究对象：鲜切苹果片（Fresh-cut apple）。切片破坏细胞结构，挥发物释放比整果快 3~5 倍，
> 褐变、发酵、失水进程肉眼可见，是「视觉+嗅觉」双通道检测的最佳研究对象。
> 前置条件：烧录最新固件，串口确认是 COM10；先看一遍「每日检查清单」（第 12 节）。

## 1. 实验目的与假设

- 目的：用电子鼻监测鲜切苹果的顶空气体变化，建立
  「气味特征 → 褐变/发酵程度」分类模型（fresh / mid / rotten）
  以及「气味特征 → 放置时间」回归模型（预测剩余货架期）。
- 假设：切片放置过程中，乙醇、酯类等挥发物释放量随时间显著上升，
  传感器阵列响应特征可区分新鲜度阶段，并能预测放置时间。
- 交付：分类模型 + 回归模型存入 enose/models/（文件名带 _slice），
  接入系统「切片检测」页面，与视觉褐变检测形成双通道。

## 2. 装置摆放（收纳箱法，零改造）

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 密封收纳箱 | 10~15 L，带密封圈，透明 | 切片挥发快，箱子不用太大 |
| 放切片的盘子 | 白色浅盘/小蒸架 | 便于观察褐变，避免果汁接触传感器 |
| USB 线出口 | 箱盖边角留缝引出，保鲜膜+胶带封口 | 不要求绝对气密 |
| 传感器朝向 | 感知面朝盘子，距切片 10~20 cm | 不贴箱壁、不贴切片 |
| 安全 | MQ 有加热丝会发烫 | 不碰传感器外壳；不贴着塑料壁 |

装置固定不动，只开盖换切片，一致性最好。

## 3. 切片标准化（控制变量，成败关键）

- 同一把刀、同一人操作；苹果洗净擦干后再切。
- 切法：对半切开 → 再切成约 1.0 cm 厚片（厚度偏差尽量 ±0.1 cm，可用两根筷子/垫块辅助定位）。
- 取中部果肉切片，两端（果萼、果梗端）不用，减少个体差异。
- 每片独立编号：s{苹果号}_{片号}，同一苹果的多片作为平行样本。
- 切完那一刻记为 0 min，立即开始计时；切片放在开放托盘上模拟货架，不盖任何东西。

## 4. 样本设计与时间点（横断面设计，推荐）

> 思路：一批切片同时切好放托盘上，到 0 / 30 / 60 / 120 / 240 min 各取 3 片进箱测一次。
> 每片只测一次，避免反复测量扰动，数据干净、样本量足。

| 项目 | 每轮（1 天） | 说明 |
| --- | --- | --- |
| 苹果数 | 3 个 | 每次买同一批，减少个体差异 |
| 每果切片 | 6 片 | 中段果肉，切完放托盘并编号 |
| 时间点 | 0 / 30 / 60 / 120 / 240 min（5 点） | 第 6 片留作备用 |
| 每时间点测 | 3 片（3 个苹果各取 1 片） | 平行样本 |
| 每轮样本数 | 15 个（5 点 × 3 片） | 约 2.5 小时完成 |

轮次安排（凑够训练数据）：
- 每天做 2 轮（上午/下午各 1 轮，用不同苹果）→ 每天 30 个样本。
- 连做 3 天 → 90 个样本（fresh/mid/rotten 大致 3 级均衡）。
- 想更稳就做 5 天 → 150 个样本。

标签设定（两个目标，一个 CSV 就能同时支持分类和回归）：
- 分类标签：0~60 min → fresh；120 min → mid；240 min → rotten（按时间划分，客观可复现）。
- 回归目标：记录放置分钟数（minutes 列），供回归模型预测剩余货架期。
- 可选增强：每时间点拍照，用系统 /slice 页面输出褐变面积%，把「视觉褐变等级」也作为分类标签备选。

## 5. 采样流程（每片约 10 分钟，拍照 + 气味配对）

> 视觉和嗅觉无法真正同时测（密封箱内不能开盖拍照），但不需要同时测：
> 褐变/发酵是分钟级缓慢过程，拍照与入箱间隔控制在 2 分钟内，对应的就是同一个品质状态。
> 所有「视觉+电子鼻」研究都采用这种短间隔配对方式，论文中说明「两通道采样间隔 ≤2 min」即可。

每时间点的操作顺序（先拍照、后测气味）：
```
到时间点
  → 托盘不动，固定机位拍照 30 秒（浅色背景、固定光源，1 张/片）
  → 立即取 3 片入箱 → 盖盖静置 3 min
  → 采集 2 min（稳态）
  → 取出切片 → 敞盖通风 5 min → 下一个时间点
```
- 照片命名与气味 CSV 一一对应：s001_slice_0min.jpg ↔ s001_slice_0min.csv。
- 这样每个样本 = 1 张照片 + 1 组气味特征 + 1 个标签（时间点/等级），融合数据集自动生成。

命令示例（在 E:\apple 下执行）：
```bash
# 基线（每天一次）
python enose\collect.py --port COM10 --label baseline --out enose\data\raw\baseline_day1.csv

# 切片样本（时间点就是标签前缀）
python enose\collect.py --port COM10 --label fresh --out enose\data\raw\s001_slice_0min.csv
python enose\collect.py --port COM10 --label fresh --out enose\data\raw\s004_slice_30min.csv
python enose\collect.py --port COM10 --label mid   --out enose\data\raw\s007_slice_120min.csv
python enose\collect.py --port COM10 --label rotten --out enose\data\raw\s010_slice_240min.csv
```

开机预热 30 min（箱盖敞开，通风）
  → 盖盖不放切片 → 空箱基线采集 2 min（--label baseline，每天早晚各一次）
  → 切苹果、摆盘（0 min）
  → 到时间点：取 3 片放盘入箱 → 盖盖静置 3 min（切片挥发快，积累时间短）
  → 采集 2 min（稳态，约 120 个点）
  → 取出切片 → 敞盖通风 5 min（读数回落）
  → 下一个时间点
```

命令示例（在 E:\apple 下执行）：
```bash

python enose\collect.py --port COM10 --label baseline --out enose\data\raw\baseline_day1.csv

# 切片样本（时间点就是标签前缀）
python enose\collect.py --port COM10 --label fresh --out enose\data\raw\s001_slice_0min.csv
python enose\collect.py --port COM10 --label fresh --out enose\data\raw\s004_slice_30min.csv
python enose\collect.py --port COM10 --label mid   --out enose\data\raw\s007_slice_120min.csv
python enose\collect.py --port COM10 --label rotten --out enose\data\raw\s010_slice_240min.csv
```

## 6. 数据管理与命名规范

```
E:\apple\enose\data\
  raw\
    baseline_day1.csv
    s001_slice_0min.csv      # s001 = 第1轮第1片
    s004_slice_30min.csv
    s007_slice_120min.csv
    s010_slice_240min.csv
    ...
  record.xlsx   # 记录表：轮次、苹果号、片号、时间点、硬度/糖度(可选)、视觉褐变%、等级
  features.csv  # preprocess.py 输出
```

- 文件命名：s{流水号}_slice_{时间点}.csv；等级写在 label 列（fresh/mid/rotten）。
- 记录表每个样本一行，时间点分钟数单独一列（回归目标，训练时用 --target minutes 需把该列加进 CSV 或特征表）。
- 异常记录：采集中断、-999、泄漏等标注，特征提取前剔除或重测。

> 小提示：回归目标列（minutes）现在 collect.py 不自动写，训练前在 record.xlsx 里维护，
> 特征提取后手动并入 features.csv 的 minutes 列即可（或用文件名里的时间点自动生成）。

## 7. 质量控制

- 漂移监测：每天早晚测空箱基线；漂移大则当天数据用基线差分校正（--baseline）。
- 重复性：随机抽 10% 切片重复测一次，特征相关 ≥0.9 为可靠。
- 剔除标准：采集时长不足、-999 占位、明显泄漏、切片厚度偏差过大。
- 环境控制：封闭室内，记录温度湿度（BME680 自动写入 CSV）；避免风扇直吹。
- 切片一致性：同一批苹果同一人切，厚度用垫块控制；切完立即编号。
- 统计验证：5 折交叉验证 + 按轮次分组验证（防同批苹果数据泄漏）。
- 配对一致性验证（融合前必做）：同一时间点 3 片平行样本，算「视觉褐变%」与「4 路 MQ 特征」的相关系数；
  若相关显著（p<0.05），说明两通道同步性成立，融合逻辑可靠。

## 8. 预实验（正式采集前 1 天）

1. 烧录最新固件，确认 OLED 与串口 11 列输出正常。
2. 预热 30 min，测空箱基线，确认读数稳定。
3. 切 2 个苹果各 3 片，跑 0 / 30 / 60 / 120 min 四个点，
   用 Excel 画 4 路 MQ 曲线，确认「放置越久，信号上升越明显」。
4. 确认曲线趋势一致后，再决定正式采集的时间点是否要延长到 360 min（6 小时）。

## 9. 正式采集安排

- 每天 2 轮（上午、下午），每轮 3 苹果 × 5 时间点 = 15 样本。
- 3 天 = 90 样本；5 天 = 150 样本。分 3~5 个采集日，穿插整理记录表。
- 同一轮 3 个苹果尽量选大小接近的；不同轮用不同批次苹果，覆盖个体差异。
- 采集期间每个时间点顺手拍一张照片存到切片视觉数据集（以后做多模态融合用）。

## 10. 建模流程（数据够了之后）

```bash
# 1. 特征提取（60 维，基线差分校正）
python enose\preprocess.py enose\data\raw --out enose\data\features.csv --baseline enose\data\raw\baseline_day1.csv

# 2. 多模型对比（RF/SVM/kNN/LR/PLS-DA，5 折交叉验证）
python enose\train.py enose\data\features.csv --compare

# 3. 分类模型：按轮次分组验证防泄漏，保存（文件名带 _slice）
python enose\train.py enose\data\features.csv --model plsda --cv group --save enose\models\freshness_slice_plsda.pkl

# 4. 回归模型：预测放置分钟数（PLSR/RF/SVR）
python enose\train.py enose\data\features.csv --mode regress --model plsr --target minutes --cv group --save enose\models\shelf_slice_plsr.pkl
```

- 模型存到 enose/models/（带 _slice 后缀），重启服务后「切片检测」页面自动加载。
- 分类（fresh/mid/rotten）用来告诉用户「现在能不能吃/要不要处理」；
  回归（剩余时间）用来做「还剩几小时货架期」的预警。

## 13. 常见问题

| 现象 | 处理 |
| --- | --- |
| 放切片后 MQ 几乎不动 | 切片太新鲜信号弱正常；静置加到 5 min；检查箱盖密封 |
| 曲线没有随放置时间上升 | 换更明显的腐败阶段样本验证；确认切片没被风扇直吹 |
| 读数一直跳 | 预热不足，等 30 min；或环境气流大，关门窗 |
| 温度/湿度 -999 | BME680 未识别，检查 I2C 接线与地址（0x76/0x77） |
| eCO2/TVOC 一直 400/0 | SGP30 基线校准中，预热 10~15 min |
| 采集中断 | 重插 USB 重启 collect.py，该样本重测 |
| 早晚基线漂移大 | 用当天基线差分校正，或分轮次建模再对比 |

## 14. 护色剂对比实验（毕设加分项，采集完成后可做）

- 三组：对照组（清水泡 1 min）/ 0.5% VC 浸泡组 / 1% 柠檬酸浸泡组。
- 每组 5 片，按 0/30/60/120/240 min 测气味 + 拍照。
- 用系统输出褐变面积% 和电子鼻特征画「褐变/信号-时间」折线，量化比较护色效果。
- 统计：单因素 ANOVA + Tukey 事后检验（系统「显著性分析」页面可做）。
- 产出：证明「系统能客观评价护色剂效果」，论文深度直接提升。
