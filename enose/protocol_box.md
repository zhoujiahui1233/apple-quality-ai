# 电子鼻苹果新鲜度检测——收纳箱法完整试验方案（方案一）

> 适用：ESP32 + MQ-2/3/7/135 阵列 + BME680 + SGP30 电子鼻装置（面包板免焊版）
> 特点：零改造。装置固定放在密封收纳箱内，只开关箱盖换苹果，一致性最好，适合新手。
> 前置条件：先烧录最新固件（OLED 显示温度/湿度/气压/eCO2/TVOC/4路MQ），串口确认是 COM10。

## 1. 实验目的与假设

- 目的：用电子鼻采集苹果顶空气体，建立「气味特征 → 新鲜度等级」识别模型，
  与视觉检测一起构成「外观 + 气味」双通道品控系统。
- 假设：不同新鲜度苹果释放的挥发性气体成分与浓度存在可检测差异，
  传感器阵列（MQ-2/3/7/135 + BME680 + SGP30）响应特征可区分新鲜度等级。
- 交付：分类模型（fresh / mid / rotten）+ 回归模型（剩余货架期），
  模型存入 enose/models/，接入系统「电子鼻」页面。

## 2. 硬件与容器准备

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 密封收纳箱 | 10~20 L，带密封圈/密封条，箱体透明 | 越大气体积累越慢，10~15 L 比较合适 |
| 放苹果的支架 | 盘子/小蒸架，把苹果垫高 | 避免果汁接触传感器和箱底 |
| USB 线出口 | 箱盖边角留一条小缝，线引出后用保鲜膜+胶带封住 | 不要求绝对气密，但要让气体大部分留在箱内 |
| 传感器朝向 | 感知面朝苹果方向，距苹果 10~20 cm | 不要贴箱壁、不要贴苹果 |
| 安全 | MQ 传感器有加热丝，通电后发烫 | 不碰传感器外壳；不要贴着塑料箱壁/苹果 |

装置整体固定不动，只开盖放苹果、关盖采集，这是收纳箱法一致性的关键。

## 3. 样本设计

- 品种：红富士（统一品种；后续可加 1 个对照品种作扩展）。
- 采购：同一批购买（同产地同批次），买回统一清洗擦干，随机编号 1~120。
- 数量：3 级 × 40 = 120 个（最少 3×30=90）。
- 存放：室温（20~28℃）自然存放模拟货架，不冷藏；记录购买日为第 0 天。
- 顺序随机化：每天从剩余样本中随机抽测，避免「先测的都是新买的」。

## 4. 新鲜度分级标准（客观指标，不能只靠目测）

每批测「三件套」客观指标（合计几十元）：

| 指标 | 工具 | 测量方法 | 备注 |
| --- | --- | --- | --- |
| 硬度 | 手持果实硬度计（8mm 探头） | 去皮，赤道部两处各测一次取均值（kgf） | 主指标 |
| 可溶性固形物 | 手持糖度计（折光仪） | 切小片挤汁滴测（°Brix） | 辅助 |
| 感官评分 | 自制评分表（下面） | 3 人独立打分取均值 | 综合参考 |

感官评分表（每人每项 1~5 分，共 5 项，满分 25）：
| 项目 | 5 分（新鲜） | 1 分（腐败） |
| --- | --- | --- |
| 色泽 | 鲜艳有光泽 | 暗淡发暗、有水渍 |
| 香气 | 果香清新 | 无果香或酒味/酸腐味 |
| 质地 | 硬脆 | 软塌、按压凹陷不回弹 |
| 表面状态 | 干爽完整 | 湿润、粘滑、有霉点 |
| 异味 | 无 | 明显异味（酒精/酸败） |

分级规则（示例阈值，正式实验前先用 5 个预实验样本标定你自己的阈值）：
- 新鲜 fresh：硬度 ≥ 5.5 kgf 且 总分 ≥ 20
- 次新鲜 mid：4 ≤ 硬度 < 5.5 kgf 或 15 ≤ 总分 < 20
- 腐败 rotten：硬度 < 4 kgf 或 总分 < 15，或出现霉斑/渗液

> 红富士硬度区间约 4~9 kgf，示例阈值必须用预实验数据替换成你自己的。

## 5. 采样流程（每样本约 22 分钟）

```
开机预热 30 min（箱盖打开，通风，读数稳定）
  → 盖盖不放苹果 → 空箱基线采集 2 min（--label baseline，每天开始/结束各一次）
  → 开盖放入 1 个苹果 → 立即盖盖 → 静置 10 min（气体积累）
  → 采集 2~3 min（稳态段，约 120~180 个采样点）
  → 开盖取出苹果 → 敞盖通风 5 min（读数回落到接近基线）
  → 测下一个样本
```

命令示例（在 E:\apple 下执行）：
```bash
# 基线（每天开始一次）
python enose\collect.py --port COM10 --label baseline --out enose\data\raw\baseline_day1.csv

# 样本（每个样本一个文件，Ctrl+C 停止）
python enose\collect.py --port COM10 --label fresh --out enose\data\raw\s001_fresh_day0.csv
```

## 6. 数据管理与命名规范

```
E:\apple\enose\data\
  raw\            # 每个样本一个 CSV（collect.py 输出）
    baseline_day1.csv
    s001_fresh_day0.csv
    s002_mid_day3.csv
    s003_rotten_day5.csv
    ...
  record.xlsx     # 记录表：编号、日期、硬度、TSS、感官分、分级结论
  features.csv    # preprocess.py 输出（每行一个样本的 60 维特征）
```

- 文件命名：s{编号}_{等级}_{天数}.csv，等级用 fresh / mid / rotten。
- 每批样本测完，把硬度/TSS/感官分填入 record.xlsx，由指标综合定等级；
  **等级就是 CSV 的 label（训练目标）**。
- 异常记录：采集中断、-999 占位、泄漏等单独标注，特征提取前剔除或重测。

## 7. 质量控制（证明数据可信，论文必需）

- 漂移监测：每天开始/结束测空箱基线，观察 4 路 MQ 基线是否漂移；
  漂移大的天，训练时用当天基线做差分校正（preprocess.py 的 --baseline 参数）。
- 重复性：随机抽 10% 样本重复采集一次，算特征级相关系数（≥0.9 认为可靠）。
- 剔除标准：采集时长不足、读数含 -999 占位、明显泄漏（开盖漏测等）。
- 环境记录：每次采集记录室温、湿度（BME680 会自动写入 CSV，直接看即可）。
- 统计验证：建模后做 5 折交叉验证；模型间比较用 McNemar 检验（系统已有 scipy）。

## 8. 预实验（正式采集前必做，约 1 天）

1. 烧录最新固件，确认 OLED 显示正常、串口输出 11 列数据。
2. 预热 30 min，测一次空箱基线，确认读数稳定（波动小）。
3. 拿 3 个苹果（新鲜、放 3 天、放 7 天）各完整跑一遍流程，
   用 Excel 画 4 路 MQ 的时间曲线，确认「放苹果后曲线明显上升」。
4. 标定分级阈值：把 3 个苹果的硬度/糖度/感官分记下来，确定你自己的分级线。
5. 预实验数据只做流程验证，不进入正式训练集。

## 9. 正式采集（数据量规划）

- 每天可测：15~20 个样本（约 6~7 小时，含预热和间歇）。
- 120 个样本约需 7~10 个采集日，可分两周完成，穿插整理记录表。
- 目标分布尽量均衡：fresh / mid / rotten 各 40 个左右。
- 采集期间同步给每个苹果拍照存到视觉数据集（可选，为以后多模态融合做准备）。

## 10. 建模流程（数据够了之后，一键跑）

```bash
# 1. 特征提取（60 维，用每天基线差分校正）
python enose\preprocess.py enose\data\raw --out enose\data\features.csv --baseline enose\data\raw\baseline_day1.csv

# 2. 多模型对比（RF/SVM/kNN/LR/PLS-DA，5 折交叉验证）
python enose\train.py enose\data\features.csv --compare

# 3. 选最好模型，按批次分组交叉验证防泄漏，保存
python enose\train.py enose\data\features.csv --model plsda --cv group --save enose\models\freshness_plsda.pkl

# 4. 回归：预测放置天数（PLSR/RF/SVR）
python enose\train.py enose\data\features.csv --mode regress --model plsr --target days --cv group --save enose\models\shelf_plsr.pkl
```

- 模型保存到 enose/models/（整果不带 _slice，切片带 _slice），重启服务后系统「电子鼻」页面自动加载。
- 120 个样本是最低体面工作量；想提高论文说服力，可加到 3 级 × 50 = 150。

## 12. 每日操作检查清单

- [ ] 开机，预热 30 min（箱盖打开）
- [ ] 记录当天室温/湿度
- [ ] 盖盖测空箱基线 2 min
- [ ] 测当天计划样本（每个：放苹果→静置10min→采2~3min→取出→通风5min）
- [ ] 每个样本测完立即填 record.xlsx（硬度、糖度、感官分、等级）
- [ ] 结束再测一次空箱基线，对比早晚漂移
- [ ] 关机，清理箱内，苹果测完即弃（不食用）

## 13. 常见问题

| 现象 | 处理 |
| --- | --- |
| 放苹果后 4 路 MQ 几乎不动 | 静置时间加长到 15 min；检查箱盖密封；苹果太新鲜信号弱是正常的，预实验先确认 |
| MQ 读数一直在跳 | 还在预热，等 30 min 后再测；或环境气流太大 |
| 温度/湿度是 -999 | BME680 没被识别，检查 I2C 接线和地址（0x76/0x77） |
| eCO2/TVOC 一直 400/0 | SGP30 正在基线校准，预热 10~15 min 后恢复 |
| 采集一半断线 | 重插 USB，重启 collect.py，该样本重测 |
| 早晚基线漂移大 | 用当天基线差分校正，或两天数据分开建模再对比 |
